Conectar Google Calendar

Necesitas un Client ID de Google Cloud. Solo se hace una vez:

  1. Entra a console.cloud.google.com y crea un proyecto
  2. Busca Google Calendar API y actívala
  3. Ve a Credenciales → Crear → ID de cliente OAuth → Aplicación web
  4. En Orígenes de JavaScript autorizados agrega la URL de tu GitHub Pageshttps://tuusuario.github.io
  5. Copia el Client ID y pégalo aquí
