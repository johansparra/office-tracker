🔗 Conectar Google Calendar

Necesitas un Client ID de Google Cloud. Sigue estos pasos:

  1. Ve a console.cloud.google.com y crea un proyecto
  2. Busca Google Calendar API y actívala
  3. Ve a Credenciales → Crear → OAuth 2.0 → Aplicación web
  4. En "Orígenes JS autorizados" agrega la URL de tu GitHub Pages
    Ejemplo: https://tuusuario.github.io
